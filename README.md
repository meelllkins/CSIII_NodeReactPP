# CSIII_NodeReactPP

Proyecto full-stack en construcción para la materia CSIII.

## ¿Qué se está construyendo?
Una aplicación web con:
- **Backend** en Node.js + Express + MySQL (API REST).
- **Frontend** en React (SPA con navegación por rutas).

La idea es gestionar entidades como **Usuarios** y **Productos**, conectando el frontend con endpoints del backend.

## Stack principal
- Node.js
- Express
- MySQL (`mysql2`)
- React (Vite)
- React Router

## Estado actual
Base inicial del proyecto preparada para continuar con:
1. Modelado de datos y conexión completa a MySQL.
2. CRUD de usuarios y productos en el backend.
3. Integración del frontend con esos endpoints.

## Ejecución esperada del proyecto
Cuando backend y frontend estén configurados en sus carpetas:

- Backend: `npm run dev` (puerto 3000)
- Frontend: `npm run dev` (puerto 5173)
